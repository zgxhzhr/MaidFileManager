# Maid File Manager

**车万女仆档案（迁移）管理器**（Maid File Manager）是一款 [Touhou Little Maid](https://github.com/TartaricAcid/TouhouLittleMaid)（车万女仆）的附属模组，核心功能只有一个：把你的女仆打包带走。

无论是换整合包重新开始，还是把单机养成的女仆带到服务器里，本模组都能让女仆数据在 1.20 / 1.20.1 / 1.21 / 1.21.1 之间自由迁移，并同时支持 Forge、NeoForge 与 Fabric 三大加载器。

> Fabric 版本基于社区非官方移植的 TLM，非车万女仆本体官方支持，如遇问题请先确认是否为移植版自身原因。

配套图文教程：<https://www.mcmod.cn/post/6715.html>

## 功能特性

- **一键导出/导入**：游戏内按 U 键唤出面板（可在「选项 → 控制设置 → 女仆文件管理」中改键），勾选女仆即可导出为 `.maid` 文件，勾选文件即可导入还原
- **批量操作**：支持同时选中多个女仆或文件，一键批量导出/导入
- **跨版本搬运**：1.20 ↔ 1.20.1 ↔ 1.21 ↔ 1.21.1 导出的 `.maid` 文件互相兼容，导入时自动完成数据迁移
- **药水效果跨版本迁移**：导出时同时保存原版 NBT（active_effects）与跨版本标准化（normalized）双份数据，导入时按目标版本自动恢复
- **万法皆通常驻 buff 保护**：禁药水模式下，按「效果 ID 命中白名单（11 种万法皆通结构女仆固定的永久常驻效果）+ Duration=-1」双条件判定，将常驻效果写入持久化标签保留，再次导出可恢复；不依赖女仆实体身份判定
- **饰品导入**：默认携带，可关闭；仅恢复车万女仆本体与万法皆通两个命名空间的饰品，一律全新生成（无附魔、不继承耐久），目标世界缺注册物品时安全跳过
- **进度导入**：默认携带，可配置是否还原女仆成就进度
- **导入后删除源文件**：导入 Tab 提供「导入后删除文件」开关（默认关闭），仅删除服务端确认生成成功的那批，失败文件原样保留
- **AI 对话数据迁移**：AI 人设（CustomSetting）、聊天历史（MaidHistoryChat，最多 512 条）、压缩摘要（MaidHistorySummary）、Token 用量跨版本完整迁移
- **安全防护**：导出时不保留背包与主副手物品，防止利用导出机制刷取物品
- **服务端统一导出**：仅 OP（权限等级 2）可用，按玩家分组导出到服务端 `maid_exports/<玩家名>/`；只写文件、永不移除女仆；需每位玩家本人同意（默认不同意）
- **服务端配置同步**：联机宿主集中管控四项开关，客户端进服自动同步
- **无残留**：卸载模组不影响已导入的女仆

## 安装

1. 安装对应版本的 Forge / NeoForge / Fabric（Fabric 还需 Fabric API）
2. 安装 Touhou Little Maid（车万女仆）模组作为前置；Fabric 用户请安装社区非官方移植版 TLM
3. 将本模组 JAR 放入 `.minecraft/mods` 文件夹
4. 启动游戏

## 使用方法

游戏目录（`.minecraft` 或整合包实例目录，与 `mods` 平级）下两个文件夹：

| 文件夹 | 用途 |
|---|---|
| `maid_exports/` | 导出结果，按玩家名分子文件夹 `maid_exports/<玩家名>/` |
| `maid_imports/` | 导入来源，把要导入的 `.maid` 文件放这里（没有可手动新建） |

1. 按 U 打开面板，在「导出」Tab 点「刷新」（列表只显示周围 128 格内、由你驯服的女仆），勾选后点导出；默认「保留原女仆在世界」开启，导出只是备份
2. 把 `.maid` 文件从旧存档的 `maid_exports/<玩家名>/` 复制到新存档的 `maid_imports/`
3. 在「导入」Tab 点「刷新」，勾选文件后点导入；可勾选「导入后删除文件」（默认关闭）；女仆生成在玩家身边安全位置并获得全新 UUID
4. 点「打开导出文件夹」可直接打开输出目录（导入 Tab 对应打开 `maid_imports/`）

## 服务端配置

四项服务端开关**默认全部开启（true）**，由联机宿主（OP）在设置中修改，客户端进服自动同步：

| 开关 | 默认 | 关闭时效果 |
|---|---|---|
| 允许客户端导入女仆 | 开启 | 所有玩家的导入被拒绝 |
| 导入时允许携带饰品 | 开启 | 饰品被丢弃 |
| 导入时允许携带进度 | 开启 | 进度数据不写入 |
| 导入时允许药水效果 | 开启 | 非白名单药水被丢弃；万法皆通 11 种常驻效果仍写入持久化标签中转保留 |

玩家侧开关「允许服务端统一导出你的女仆」**默认不同意（false）**，需玩家本人开启后，OP 才能在统一导出中导出该玩家的女仆。

## 服务端统一导出（仅 OP）

- **GUI**：导出 Tab 点「统一导出」进入统一导出模式（按钮变为「返回单独导出」），列表按玩家分组显示「▼ 玩家名（N 只女仆）」，未同意的玩家标注 [未同意导出]；提交后文件保存到服务端 `maid_exports/<玩家名>/`
- **命令**：`/maidfile exportall` 一键导出所有已同意玩家的女仆（命令搜索半径 256 格；GUI 浏览列表搜索半径 128 格）
- 实体查找采用「直接取实体 → 128 格 AABB → 全维度 AABB」三级查找防漏
- **范围限制**：只能导出每位玩家周围加载范围内、由其本人驯服的女仆；未加载区块、魂符/相片/胶卷等容器内的女仆无法覆盖。换服或灾备前请通知玩家把女仆带到身边

## 数据保留情况

| 数据 | 结果 |
|---|---|
| 主人驯服关系 | 保留（找不到原主人时生成为未驯服，用蛋糕重新驯服即可） |
| 名字 / 模型 | 保留（目标端缺模型时显示为博丽灵梦） |
| 血量 | 保留（至少 80；被雷劈渡劫的至少 100；超过 256 截断为 256） |
| 攻击力 | 保留（数据异常时恢复为默认 2.0） |
| AI 对话数据 | 保留（人设、聊天历史、摘要、Token 用量） |
| 饰品 / 药水效果 / 进度 | 默认保留，可分别关闭 |
| 背包与主副手物品 | 不保留（导出前请先取回） |
| 原 UUID / 着火、坠落等运行时状态 | 不保留（导入时生成新 UUID） |

## 版本历史

### v1.3.0
- 新增：药水效果跨版本迁移（原版 NBT + 标准化双份数据，按目标版本恢复）
- 新增：万法皆通常驻 buff 白名单保护（11 种固定效果 + Duration=-1 双条件，禁药水服务器下经持久化标签中转保留）；删除原女仆身份判定（实体类型命名空间/持久化标记/复合条件），改为纯效果判定；`MaidFileData.spellMaid` 字段与 `[万法皆通附属]` 文件名前缀一并删除（旧 v4 文件含 `spell_maid` 键时读取忽略，向后兼容）
- 新增：导入后删除源文件开关（默认关闭，仅删除服务端确认生成成功的文件）
- 新增：进度导入开关
- 新增：Fabric 平台支持（1.20 / 1.20.1 / 1.21 / 1.21.1，基于社区非官方移植 TLM）
- 服务端统一导出全员正式可用（v1.2.0 仅声明未实现）：三级实体查找防漏、按玩家分组保存
- 新增：服务端配置同步（允许导入 / 饰品 / 进度 / 药水四项开关，默认全部开启）
